# Fuel

![Next.js](https://img.shields.io/badge/Next.js-16-000000?style=for-the-badge&logo=next.js&logoColor=white)
![TypeScript](https://img.shields.io/badge/TypeScript-strict-3178C6?style=for-the-badge&logo=typescript&logoColor=white)
![Prisma](https://img.shields.io/badge/Prisma-7-2D3748?style=for-the-badge&logo=prisma&logoColor=white)

Личный трекер питания и тренировок: лог еды со сканером штрихкодов, конструктор своих составных блюд, алгоритмическая генерация меню на месяц с автосборкой списка покупок, тренировки с автоопределением личных рекордов.

## Почему так

Извлечён из модулей `nutrition`/`workouts` [GetGrip](https://github.com/Moonsh1nee/habitforge-frontend) — по тому же плейбуку, что и [Wisely](https://github.com/Moonsh1nee/Wisely) с финансами: экспорт-скрипт в старом бэкенде → идемпотентный импорт (дедуп по `sourceId`) → сверка количества строк с продом → удаление модуля из GetGrip настоящей Alembic-миграцией с down-путём. Дальше рос уже самостоятельно, YaZio-вдохновлённые фичи (штрихкоды, составные блюда, генерация меню) добавлены уже здесь, а не унаследованы.

## Возможности

| Раздел | Что внутри |
|---|---|
| **Дневник питания** | Лог приёмов пищи по типам, автопересчёт БЖУ по граммам съеденного (а не копирование БЖУ продукта как есть) |
| **Поиск продуктов** | Интеграция [Open Food Facts](https://world.openfoodfacts.org/) — поиск по названию и **сканер штрихкодов** через камеру телефона (`@zxing/browser`) |
| **Свои продукты** | Составные блюда из нескольких ингредиентов с граммовками — БЖУ считается и фиксируется на момент сохранения (редактирование рецепта задним числом не меняет уже залогированные дни) |
| **Рецепты** | Название, инструкции, БЖУ на порцию (делится на количество порций, а не на общий вес — другая семантика, чем у составных блюд) |
| **Генератор меню** | Алгоритмическая расстановка рецептов по дням месяца — без ИИ, детерминированно, см. ниже |
| **Список покупок** | Автосборка из сгенерированного меню, агрегация по нормализованному названию, чекбоксы сохраняются в БД (переживают перезагрузку страницы) |
| **Тренировки** | Лог тренировок с сетами/повторами/весом, библиотека упражнений (системные + свои), **автоопределение личных рекордов** при каждом логе |
| **Дашборд** | Калории за 14 дней, объём тренировок за 12 недель, прогресс к целям активного плана питания |
| **Вход через GetGrip** | OAuth2-логин через собственный identity-провайдер [GetGrip](https://github.com/Moonsh1nee/habitforge-backend). Публичного инстанса GetGrip сейчас нет, так что работает только против локально запущенного бэкенда; обычный вход по email/паролю от этого не зависит |

## Технически интересное

**Генерация меню** (`src/lib/menu-generation.ts`) — то, что стоит посмотреть в первую очередь. Чистая функция без единого похода в БД, поэтому легко тестируется: 9 юнит-тестов, включая проверку "ни один рецепт не повторяется в любом 7-дневном окне на 31 день / 20 рецептов". Технические решения:
- Псевдослучайность через собственный `mulberry32` (`src/lib/seeded-rng.ts`), никогда не `Math.random()` — генерация воспроизводима для одного и того же seed, что и делает такой тест возможным в принципе
- Пул рецептов на каждый приём пищи перемешивается независимо, повторное перемешивание при исчерпании, с исключением последних N дней (cooldown) из повтора
- Если пул рецептов меньше cooldown — ограничение мягко ослабляется автоматически и наружу возвращается **структурированное** предупреждение (`{mealType, reason, poolSize}`, а не готовая строка) — модуль генерации остаётся независимым от языка интерфейса, текст тоста собирает уже UI-слой
- При заданных целях по калориям порции масштabируются в пределах 0.75–1.5×, с округлением до 0.25 — без плана каждая порция остаётся 1×

**Штрихкод-сканер**: сознательно не полагается на нативный `BarcodeDetector` API (его нет в iOS Safari/Firefox) — единственный код-путь через `@zxing/browser` работает везде одинаково. Поле ручного ввода штрихкода видно всегда, не спрятано за фича-детект — это и accessibility-фолбэк, и единственный способ проверить фичу без реальной камеры (Playwright её подделать не может).

## Стек

Next.js 16 (App Router) + TypeScript + Prisma 7 (driver-adapter, SQLite) + Tailwind v4 + Auth.js v5 + `@zxing/browser` + Recharts.

## Быстрый старт

```bash
npm install
cp .env.example .env        # свой AUTH_SECRET
npx prisma migrate deploy
npx prisma generate         # Prisma 7 не делает это на install автоматически
npm run db:seed             # demo@fuel.local / demo12345, 15 системных упражнений, 8 демо-рецептов
npm run dev                 # http://localhost:3001
```

## Тесты

```bash
npm run test    # 64 теста
npm run lint
npm run build
```
